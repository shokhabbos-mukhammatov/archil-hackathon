Scoped Runner

Per-call access for agents that have no sandbox

Start a run

Each run gets three fresh disks of its own, deleted at the end. “Measure access” makes one harmless probe per class, plus one with no limits for comparison.

Access classes

Fixed rules sort every tool call into a class; the model never chooses. A command that chains, pipes or redirects always gets other. The API key is never inside a call: for test, Archil adds it to requests to your service on the way out.
